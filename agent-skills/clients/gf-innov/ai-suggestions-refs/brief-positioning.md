# Brief positioning notes

Use `brief.json` as the source of truth for the current commercial umbrella.

## When it changes

If `business.model`, `mainOffer`, or `customerType` changes, update any suggestion logic or example phrasing that depends on positioning.

### Example

A broader model like `B2B consulting + services + workshops` should be treated as:
- consulting is part of the offer, not an adjacent add-on
- suggestions may reference advisory, implementation, workshops, and delivery together
- do not keep writing copy that implies the company is only a workshop business

## Session note

During a brief update, the model was expanded from `B2B services + workshops` to `B2B consulting + services + workshops`. Future suggestions should read the broader positioning from the brief before proposing actions or copy.
