# GF post drafting reference

> NOTE (2026-07-02): superseded where it conflicts with gf-instagram-strategy.md — Instagram-only is the current strategy; this file remains for background.

This reference captures the practical drafting rules observed while creating GF posts.

## Useful facts from the current client setup

- Audience: German SMEs, innovation managers, CTOs, HR/L&D leads.
- Tone: direct, engineer-to-engineer, allergic to buzzwords.
- Voice: first-person founder voice; Martin narrates the post body.
- Preferred platforms: LinkedIn first, then YouTube.
- Core theme: from AI demos to AI in production.

## Safe drafting checklist

Before finalizing a draft, check:

- Does the hook name a real workflow, tool, or lesson?
- Is the body concrete enough to feel shipped, not aspirational?
- Did you avoid language from the banned-words list?
- Did you stay within current plan pillars/campaigns?
- Did you avoid client names, pricing, revenue, and unreleased work unless explicitly approved?
- Is the CTA simple and aligned with the campaign?

## Common strong post angles

- a workflow that shipped this week
- a lesson from deleting scope
- a tool comparison grounded in actual use
- a workshop preview or recap
- a founder note about production over demos

## Practical defaults

- Hook length: short, punchy, one idea.
- Paragraphs: keep them short for LinkedIn readability.
- Hashtags: 3-5, with at least one named tool tag when technical.
- Status: `in_review` until Martin approves.

## Drafting caution

If a post would need a confidential client reference or a pricing claim to make sense, stop and rewrite the angle instead of forcing it through.
