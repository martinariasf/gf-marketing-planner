# Instagram image iteration notes for GF

## What changed in this session
- The user wanted a GF Instagram post cover that was easier to read and better balanced.
- They explicitly preferred receiving new image iterations directly in chat as `MEDIA:` attachments, not only via file paths or folder references.
- We iterated from text-heavy layouts toward a cleaner composition with real GF branding, a workflow visual, and more intentional use of empty space.
- The main lesson was that when text starts overlapping or the canvas feels too empty, the fastest fix is usually to simplify the text block and add structural anchors (bands, cards, dividers, visual diagrams) rather than adding more copy.

## Practical checklist
1. Save the image asset to the project.
2. Update the post JSON and manifest.
3. Send the image back to the user in chat with `MEDIA:` for direct review.
4. If the user flags overlap or emptiness, iterate on composition before adding more text.
5. Keep the logo real, legible, and within safe margins.
