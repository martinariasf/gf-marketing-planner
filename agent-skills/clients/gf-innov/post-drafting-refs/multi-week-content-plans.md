# Multi-week content plans (commercial-focus arcs)

When the user asks for a weekly/monthly content plan (not a single post):

1. **Audit the full calendar first** (`GET /posts`, all statuses). Group existing
   posts by angle and present the "already covered" table BEFORE proposing
   anything. Repeating an angle is a grave strategy error for this client; the
   plan's value is in the new angles.
2. **Structure the plan as a strategic arc**, not a random list. A proven 4-week
   shape: DOLOR (agitate the pain) → PLACER (show the desirable outcome) →
   PRUEBA (proof, numbers, behind-the-scenes) → CONVERSIÓN (testimonials,
   manifesto, CTA-forward). Every piece hits a pain point AND a pleasure point.
3. **Vary formats deliberately**: mix short reels (15s), long reels (30–45s),
   carousels, single images, LinkedIn long-form and document posts. IG is the
   main channel; LinkedIn amplifies.
4. **Design every piece to work double duty: organic feed AND paid boost.** The
   client boosts already-published posts; they do NOT create separate ad-only
   content. So every piece needs a hook in the first seconds/lines and a clear
   CTA that survives being boosted.
5. **Humor style**: intelligent, direct-to-the-pain-point humor. Memes or short
   funny clips belong as icebreaker slide 1 inside value carousels, never as
   standalone filler.
6. **Language strategy (GF, Aug 2026):** content 100% in English; videos get
   Spanish subtitles for the LATAM audience. Interact with Pilar in Spanish;
   drafts in English.
7. **Feed-density context:** when the feed is still thin, a plan doubles as
   feed-filling before any boosting starts; say so in the proposal.
8. Present the plan as a week-by-week Markdown table (day, format, piece, unique
   angle) and wait for the OK before creating drafts in the dashboard.
