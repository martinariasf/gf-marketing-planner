# Instagram adaptation notes for GF post drafting

Captured from a June 2026 drafting session where the user corrected two things:

- The original cover used the wrong logo treatment.
- The post was meant for Instagram, not LinkedIn.

## Practical rules

- Treat the requested platform as authoritative. Do not default to LinkedIn copy length or structure when the user asks for Instagram.
- Use a square image by default for Instagram unless the user explicitly asks otherwise.
- Keep the caption tighter than a LinkedIn draft: fewer paragraphs, shorter lines, and a single sharp takeaway.
- Verify the branded logo treatment visually before handoff. If the raw logo looks cluttered, create a cleaner composited version rather than forcing the original asset.
- When generating a cover, ask for a readable feed-size headline and minimal supporting text.
- For GF, prefer the actual logo treatment to be small, clean, and legible in a corner instead of oversized or distorted.

## Good Instagram cover checklist

- Headline readable at thumbnail size
- Workflow or concept visible immediately
- Whitespace preserved
- No AI-stock clutter
- Logo placement looks intentional, not pasted on
