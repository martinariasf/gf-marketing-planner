# Session note: 2026-06-04 post creation

This session reinforced a practical drafting pattern for GF posts:

- A vague request like “vamos a crear un post” can be handled without extra clarification when the campaign context is available.
- The safest default is a fresh founder-POV angle tied to the current quarter theme.
- For this run, the chosen angle was owner-first: an AI project fails when nobody owns the workflow.
- The draft was created directly as `in_review` and added to `posts/index.json`.
- No image was added because the user did not ask for one; the assistant should still offer image support after the draft.

Use this as a reminder to keep the first draft concrete, narrow, and easy to approve.
