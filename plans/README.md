# Plans

One dated technical plan per task, named `YYYY-MM-DD-<slug>-technical-plan.md`.

- **`plans/`** — plans for work that is still open: not built, in flight, or
  built on `experimental` but not yet promoted to production.
- **`plans/archive/`** — plans whose work has shipped to production, plus the
  early V2/V3/V4 staging plans that predate the per-task plan convention.

Move a plan to `archive/` once its work is live on `marketing.gfinnov.com`.
